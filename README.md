# Darija Sentiment Dashboard

Plateforme Big Data NLP d'analyse de sentiment en temps réel des commentaires clients d'Algérie Télécom, en dialecte algérien (Darija).

## À propos

Dashboard interactif construit avec Dash/Plotly, connecté à MongoDB, intégrant un chatbot basé sur Groq LLaMA 3.3. Le modèle de classification utilise une architecture hybride DziriBERT + TF-IDF avec 96.18% d'accuracy.

**Stack technique :** Dash, Flask, MongoDB, Kafka/Spark, Groq LLaMA 3.3, DziriBERT
